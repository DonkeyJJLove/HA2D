# HA2D Process Guard

HA2D is maintained as a persistent-context / Human–AI state experiment. The primary failure mode is **semantic or authority drift hidden by an apparently coherent state**.

## State chain

```text
SEED
→ PCE / context state
→ MCV temporary state
→ SNAP / THOUGHT / MORPH delta
→ revision decision
→ persistent state
```

## Invariants

- temporary state (`MCV`) must not silently become persistent authority;
- every accepted semantic transition needs provenance and revision context;
- symbolic coherence is not treated as empirical truth;
- HUD representation must remain a view of state, not the source of state;
- `_neuro` metrics are experimental process descriptors, not physiological measurements;
- generated context is reviewable as delta against a prior state.

## `_neuro` / EEG-like state interpretation

```text
baseline = accepted persistent context
burst    = rapid SNAP / THOUGHT accumulation
coupling = coordinated activation across context structures
 drift   = semantic identity no longer explained by provenance
recovery = revision to a reconstructable accepted state
```

## Review loop

```text
accepted PCE
→ delta / SNAP inventory
→ semantic + mandate check
→ falsification
→ revision
→ persistence decision
→ provenance record
```

No semantic self-description is sufficient evidence for its own correctness. Assertions that leave the internal model must be externally validated where validation is possible.
